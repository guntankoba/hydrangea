## 全体仕様（共通）
- 回答入力は原則 **ひらがな**。後続で**漢字昇格 UI**（タイル選択）。
- ヒントは **3 段階**＋フェイルセーフ（ほぼ答え）。
- 入力正規化：前後・全角空白除去／カタカナ→ひらがな変換／記号除去。
- 触覚（任意）：正解=1短振動、誤答=2短振動。
- 進行：ステージごとに `letters[]` に**1文字カード**を蓄積→ステージ末尾で合成・判定。
- **大問（ステージ最終回答）の入力許容**：各ステージの**最終回答は「ひらがな or 漢字」のどちらでも正解**（例：`あきはばら` **または** `秋葉原`）。小問（1文字取得問題）はひらがな限定。
- **色トークン**：
  - `--color-accent-akiba: #0d221e`（ST2 抽出枠・FINAL入力欄）
  - `--color-accent-shinjuku: #ffc0cb`（**ST1 と ST3** のアクセント）
  - `--slot-fg-dark: #FFFFFF`（暗色背景用 文字色）
  - `--slot-fg-light: #000000`（淡色背景用 文字色）

// 同意画面ステート（PRE_TOS）

  agreed: boolean;      // チェック状態
  openedOnce: boolean;  // 利用規約テキストを一度でも開いたか（進行条件には使わない）

# PRE_TOS｜偽の利用規約 同意画面（ログイン直後）
- **目的**：ゲーム説明の前に「偽の利用規約」への同意を取得（体験の遊び心）。
- **遷移**：ログイン（パスワード入力）→ **PRE_TOS** → ゲームの説明 → ST1（金町）。

## 画面仕様
- **id**: `PRE_TOS`
- **タイトル**: 利用規約
- **UI**:
  - **チェックボックス**：「同意する」
    - ON/OFF 可能。**読まずにチェック可能**（仕様要件）。
  - **規約本文**：**タップで展開**して読めるテキストコンポーネント（アコーディオン/モーダルいずれか）。
    - 初期状態：折りたたみ（閉）。
    - サンプル文：ダミーの段落（後日差し替え）。
  - **ボタン**：「利用開始する」
    - **有効化条件**：チェックボックス `agreed === true` のときのみ活性。
    - クリックで次画面（ゲーム説明）へ。
- **注意**：規約本文を開いていなくても**進行可能**（`openedOnce` は分析用途のみ）。

## ステート・判定
- `TosState.agreed` が `true` のときだけ前進可。
- アナリティクス（任意）：
  - `agreed_toggle_count`、`openedOnce`、滞在秒数。

# ST2｜秋葉原（思い出ベース5問 → 時系列ソート → あきはばら）

## ST2 概要
- 目的：思い出を題材に **5 問**解いて**各1文字**取得 → **実体験日**でカードを**古い→新しい**に並べ替え → 連結 **`あきはばら`** → 昇格 **秋葉原**。
- 取得文字：**あ／き／は／ば／ら**。
- プレースホルダ日付：`{DATE_A} {DATE_K} {DATE_HA} {DATE_BA} {DATE_RA}`（実体験で置換）。
- **出題順は固定**：Q1→Q5 の順で出題します（FINAL で日付順並べ替え）。

### ST2 共通仕様
- 正規化・触覚・ヒント段階は ST0 の共通仕様に従う。
- クリア時の保存：
  ```ts
  letters.push({ id:'ST2_Qx_*', letter:'*', memoryTitle:'*', dateISO:'{DATE_*}' })
  ```

### ST2 回答欄（UI）共通仕様
- **入力**：すべて**ひらがな**のみ受け付け（カタカナは自動ひらがな化）。
- **枠（スロット）**：1 文字=1 枠の**等幅ボックス**で表示し、**あ・き・は・ば・ら**に該当する**ターゲット枠の背景色を #0d221e**（UIトークン例：`--slot-target-bg: #0d221e`）。
- **文字色**：背景が `#0d221e` の入力枠の**文字色は #FFFFFF**。
- **事前入力（ダミー）**：各問の回答欄に、**“あきはばら”に含まれないひらがな 1 文字をランダムで 1 枠だけ**事前入力。例：Q1（なぞとき）→ `◯ぞ◯◯` のように 1 枠だけランダム文字を入れておく。
- **キーボード**：モバイルは**かなキーボード**を推奨（`inputmode="kana"` 相当）。
- **視認性**：ターゲット枠は背景 `#0d221e` ＋**下線**も付与し色覚多様性に配慮。
- **例示表記**：本仕様上は未入力枠を**`◯`**、事前入力されたランダム1文字を**実文字**で示す。

## ST2_FINAL｜時系列並べ替え → 連結 → 漢字昇格
- **id**: `ST2_FINAL_TIMELINE`
- **タイトル**: 時系列で ならべて こたえを作れ
- **UI**:
  - **カード表示**：Q1〜Q5の**回答語**を、各Qと同じ**スロット表示**で再掲。
    - 各カード内の**ターゲット枠の背景色は #0d221e／文字色 #FFFFFF**（＝抽出対象）。
    - 例：Q1（なぞとき）→ `◯ぞ◯◯`（最後の枠が #0d221e／白文字）。
  - **ドラッグソート**：5枚のカードを**古い日付 → 新しい日付**に並べ替える。
  - **入力欄**：1行テキスト。**背景 #0d221e／文字色 #FFFFFF**（UIトークン：`--final-input-bg:#0d221e; --final-input-fg:#FFFFFF`）。
- **指示**:
  - **■色（#0d221e）を目印**に、カードを**古い→新しい**へ並べ替えろ。
  - 並べ替えの順で、各カードの**■色の枠の文字だけ**を抜き出して**連結**し、下の欄に入力せよ。
- **入力**: 連結した語（**ひらがな5文字** もしくは **漢字**）／期待解：`あきはばら` **or** `秋葉原`
- **判定**:
  - 並べ替え後の `letters` を **dateISO 昇順**で評価。
  - 入力は正規化後 `=== 'あきはばら'` **または** 文字列一致 `=== '秋葉原'`。
- **誤答**:
  - 並び違い→「**古い→新しい** だよ。**■色の枠**の文字を順に抜き出しているか確認してね。」
  - 文字ミス→「並んだ**■色の枠**の文字だけを**そのまま**入力してね。」
